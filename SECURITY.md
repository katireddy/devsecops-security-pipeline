# Security Policy

Do not publish exploit details in a public issue. Use GitHub private vulnerability reporting if enabled, or contact the repository maintainer privately.

Include the affected component, impact, reproduction steps and suggested mitigation. Never include real credentials or personal data.

This is a demo application. Run dynamic scans only against this local demo or systems for which you have explicit written authorization.

Never commit credentials, tokens, private keys or production data. If a secret is exposed, revoke or rotate it immediately; deleting the commit alone is not sufficient.
